# Vault (internal knowledge)

The Obsidian knowledge base of **internal** VPTI knowledge — process, OSS/INATRADE
system notes, and market intelligence — indexed into FAISS with local embeddings.

Regulation text does **not** live here; it comes from `pasal-id` at query time
(ADR-0002). Keep this vault to internal/process/market content only.

Folder taxonomy (from the handoff): `01_POLICY`, `02_REGULATION` (references only,
not authoritative text), `03_STANDARDS`, `04_PROCESS`, `05_SYSTEM`, `06_DATA`,
`07_VPTI_OPERATION`, `08_MARKET_INTELLIGENCE`, `09_AI_INSIGHTS`, `10_EXECUTION`.
